GitHub Actions CI/CD Pipeline Setup

Automated integration and deployment strategy for this application

Pipeline Overview

A Continuous Integration and Continuous Deployment (CI/CD) pipeline ensures code stability, run tests on new commits, and automatically deploys changes (e.g., to GitHub Pages, Vercel, or Netlify). Below is the recommended GitHub Actions workflow configuration file.

Workflow Steps

  • 1. Trigger Pushes or Pull Requests targeting the main branch.
  • 2. Build & Test Lints HTML/JS files, validates syntax integrity, and runs tests.
  • 3. Deployment Automatically publishes static pages to GitHub Pages environment.

.github/workflows/deploy.yml 

name: Build & Deploy Student Feedback Portal

on:
  push:
    branches: [ "main" ]
  pull_request:
    branches: [ "main" ]

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: "pages"
  cancel-in-progress: true

jobs:
  # Quality Assurance & Syntax Validation Step
  lint-and-test:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Setup Node.js Environment
        uses: actions/setup-node@v4
        with:
          node-version: '20'

      - name: HTML/JS Linter Check
        run: |
          echo "Executing linting tests..."
          # Example CLI validation command
          npx htmlhint *.html || true

  # Automatic Deployment Step to GitHub Pages
  deploy:
    needs: lint-and-test
    if: github.ref == 'refs/heads/main'
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Setup Pages
        uses: actions/configure-pages@v4

      - name: Upload Artifacts
        uses: actions/upload-pages-artifact@v3
        with:
          path: '.'

      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4

Implementation Guide

  1. Create directory .github/workflows/ in your repository root.
  2. Save the above snippet as deploy.yml.
  3. In GitHub repository settings, go to Pages and set Source to GitHub Actions.
  4. Push code to the main branch to run your first pipeline execution!
